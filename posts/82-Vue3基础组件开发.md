# Vue 3 基础组件开发

> **分类：前端框架** | **难度：入门 → 进阶** | **前置知识：HTML/CSS/JS 基础**

## 为什么需要掌握基础组件开发？

在 Vue 项目中，**组件是构建 UI 的基本单元**。无论你使用的是 Element Plus、Ant Design Vue 还是 Naive UI，这些第三方组件库都无法覆盖所有业务场景。实际开发中，你几乎一定会遇到以下需求：

- 一个带搜索/清空/多选的下拉框（UI 库的基础 Select 做不到）
- 一个支持拖拽排序的列表
- 一个可复用的表单容器，自带校验和提交状态
- 一个通用的图片上传预览组件
- 一个带骨架屏的卡片加载组件

**基础组件**就是介于「原生 HTML 元素」和「业务组件」之间的中间层——它不包含具体业务逻辑（如订单列表、用户信息），但提供了高度可复用的 UI 能力。

本文将从零开始，系统讲解 Vue 3 组件开发的方方面面。

## 一、组件的本质与生命周期

### 1.1 什么是组件？

一个 Vue 组件本质上是一个拥有预定义选项的 JavaScript 对象：

```vue
<!-- MyButton.vue -->
<template>
  <button class="my-btn" :class="type" @click="handleClick">
    <slot></slot>
  </button>
</template>

<script setup lang="ts">
// 这就是一个最简单的组件
defineProps<{
  type?: 'primary' | 'default' | 'danger'
}>()

const emit = defineEmits<{
  click: [e: MouseEvent]
}>()

const handleClick = (e: MouseEvent) => {
  emit('click', e)
}
</script>

<style scoped>
.my-btn { padding: 8px 16px; border-radius: 4px; cursor: pointer; }
.my-btn.primary { background: #409eff; color: white; border: none; }
.my-btn.danger { background: #f56c6c; color: white; border: none; }
.my-btn.default { background: white; border: 1px solid #dcdfe6; }
</style>
```

### 1.2 SFC 单文件组件结构

Vue 的 **SFC（Single File Component）** 是 `.vue` 文件的标准结构：

| 区域 | 作用 | 是否必须 |
|------|------|---------|
| `<template>` | HTML 模板，只能有一个根元素（Vue 2）/ 支持多根（Vue 3） | ✅ 必须 |
| `<script>` 或 `<script setup>` | 组件逻辑代码 | ⚠️ 可选（纯展示组件不需要） |
| `<style scoped>` | 样式，`scoped` 限定样式只作用于当前组件 | ⚠️ 可选 |

```vue
<template>
  <!-- 模板区域 -->
</template>

<script setup lang="ts">
// 组合式 API（推荐）
</script>

<style scoped>
/* 局部作用域样式 */
</style>
```

### 1.3 生命周期钩子

生命周期是组件从创建到销毁的全过程。理解它对处理副作用（请求、定时器、事件监听）至关重要：

```
创建阶段：
  setup() ──→ onBeforeMount() ──→ onMounted()
                    ↓                        ↑
挂载阶段：          DOM 已渲染完成，可以操作 DOM

更新阶段：
  onBeforeUpdate() ──→ onUpdated()
       ↓                      ↑
数据变化触发重新渲染

卸载阶段：
  onBeforeUnmount() ──→ onUnmounted()
         ↓                   ↑
    清理定时器/事件监听/DOM 引用
```

**常用生命周期速查：**

```typescript
import { onMounted, onUnmounted, onBeforeUnmount, watch } from 'vue'

onMounted(() => {
  // ✅ DOM 已挂载，适合：
  // - 获取 DOM 元素尺寸
  // - 初始化第三方库（ECharts、Swiper）
  // - 发起初始数据请求
  console.log('组件已挂载')
})

onBeforeUnmount(() => {
  // ⚠️ 组件即将销毁，DOM 还在
  // 适合做最后的清理工作
})

onUnmounted(() => {
  // ✅ 组件已完全销毁
  // 必须清理：定时器、事件监听、WebSocket 连接等
})
```

**最佳实践：** 在 `onMounted` 中初始化的资源，务必在 `onUnmounted` 中清理：

```typescript
// ❌ 错误示例：忘记清理定时器
onMounted(() => {
  setInterval(() => { /* ... */ }, 1000)
})

// ✅ 正确示例：配对清理
let timer: number

onMounted(() => {
  timer = window.setInterval(() => { /* ... */ }, 1000)
})

onUnmounted(() => {
  clearInterval(timer)  // 必须清理！
})
```

## 二、组件通信：Props 与 Emits

### 2.1 Props — 父传子

Props 是组件对外暴露的**配置接口**，决定了组件的可复用性：

```vue
<!-- UserCard.vue -->
<template>
  <div class="user-card">
    <img :src="avatar" :alt="name" class="avatar" />
    <h3>{{ name }}</h3>
    <p>{{ role }}</p>
    <!-- 默认插槽放额外内容 -->
    <slot></slot>
  </div>
</template>

<script setup lang="ts">
interface Props {
  name: string           // 必填
  role?: string          // 可选，有默认值
  avatar?: string        // 可选
  size?: 'sm' | 'md' | 'lg'  // 枚举约束
}

const props = withDefaults(defineProps<Props>(), {
  role: '成员',
  avatar: 'https://api.dicebear.com/7.x/avataaars/svg?seed=default',
  size: 'md'
})
</script>
```

**使用方式：**

```vue
<UserCard
  name="张三"
  role="前端工程师"
  size="lg"
>
  <span>🎉 入职 3 年</span>  <!-- 插槽内容 -->
</UserCard>
```

### 2.2 Props 类型检查表格

| 类型写法 | 说明 | 示例 |
|---------|------|------|
| `String` / `string` | 字符串 | `'hello'` |
| `Number` / `number` | 数字 | `42` |
| `Boolean` / `boolean` | 布尔值 | `true` |
| `Array` / 数组类型 | 数组 | `[1, 2, 3]` |
| `Object` / 对象类型 | 对象 | `{ a: 1 }` |
| `Function` / 函数类型 | 函数 | `(n) => n * 2` |
| 自定义类型 | 接口/联合类型 | `\| 'sm' \| 'lg'` |

**Props 校验规则：**

```typescript
const props = defineProps<{
  // 基本类型
  title: string              // 必须提供
  
  // 可选 + 默认值
  count?: number             // 可选
  
  // 联合类型（枚举效果）
  theme?: 'light' | 'dark'
  
  // 对象/数组默认值需要用工厂函数
  items?: string[]
  
  // 函数类型
  onChange?: (value: string) => void
}>()
```

### 2.3 Emits — 子通知父

子组件通过 `emit` 向父组件传递事件和数据：

```vue
<!-- SearchInput.vue -->
<template>
  <div class="search-input">
    <input
      v-model="keyword"
      @input="handleInput"
      @keyup.enter="handleSearch"
      placeholder="搜索..."
    />
    <button @click="handleSearch">🔍</button>
    <button v-if="keyword" @click="handleClear">✕</button>
  </div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const keyword = ref('')

const emit = defineEmits<{
  search: [value: string]   // 带参数的事件
  clear: []                 // 无参事件
  input: [value: string]    // 实时输入
}>()

const handleInput = () => {
  emit('input', keyword.value)
}

const handleSearch = () => {
  if (keyword.value.trim()) {
    emit('search', keyword.value.trim())
  }
}

const handleClear = () => {
  keyword.value = ''
  emit('clear')
}
</script>
```

**父组件监听：**

```vue
<template>
  <SearchInput
    @search="onSearch"
    @clear="onClear"
    @input="onInput"
  />
</template>

<script setup lang="ts">
const onSearch = (value: string) => {
  console.log('搜索:', value)
  // 执行搜索逻辑...
}

const onClear = () => {
  console.log('已清空')
}

// 防抖处理实时输入
const onInput = useDebounceFn((value: string) => {
  console.log('防抖后的输入:', value)
}, 300)
</script>
```

### 2.4 v-model 双向绑定

`v-model` 是 props + emit 的语法糖。Vue 3 支持多个 v-model：

```vue
<!-- MyModal.vue - 支持 v-model:visible -->
<template>
  <div v-if="visible" class="modal-overlay" @click.self="close">
    <div class="modal-content">
      <slot></slot>
    </div>
  </div>
</template>

<script setup lang="ts">
const props = defineProps<{ visible: boolean }>()
const emit = defineEmits<{
  'update:visible': [value: boolean]
}>()

const close = () => {
  emit('update:visible', false)
}
</script>
```

**使用：**

```vue
<MyModal v-model:visible="showDialog">
  <p>弹窗内容</p>
</MyModal>
```

## 三、插槽（Slots）的灵活运用

插槽是组件灵活性的核心机制，让父组件可以向子组件注入任意内容。

### 3.1 三种插槽对比

| 插槽类型 | 语法 | 使用场景 |
|---------|------|---------|
| **默认插槽** | `<slot></slot>` | 简单内容替换 |
| **具名插槽** | `<slot name="header"></slot>` | 多个位置注入不同内容 |
| **作用域插槽** | `<slot :data="item"></slot>` | 子组件向父组件传递数据 |

### 3.2 默认插槽

```vue
<!-- Card.vue -->
<template>
  <div class="card">
    <div class="card-body">
      <slot>这是默认内容，父组件没传时显示</slot>
    </div>
  </div>
</template>
```

### 3.3 具名插槽

```vue
<!-- PageLayout.vue -->
<template>
  <div class="page-layout">
    <header class="page-header">
      <slot name="header">默认标题</slot>
    </header>
    <main class="page-main">
      <slot></slot>  <!-- 默认插槽作为主体 -->
    </main>
    <footer class="page-footer">
      <slot name="footer">
        <span>© 2026 My App</span>
      </slot>
    </footer>
  </div>
</template>
```

```vue
<!-- 使用 -->
<PageLayout>
  <template #header>
    <h1>自定义页面标题</h1>
  </template>
  
  <p>这里是页面主体内容...</p>
  
  <template #footer>
    <span>自定义底部版权信息</span>
  </template>
</PageLayout>
```

### 3.4 作用域插槽（重点）

**作用域插槽是最强大的插槽形式**——子组件把数据"透传"给父组件，由父组件决定如何渲染：

```vue
<!-- Table.vue - 通用表格组件 -->
<template>
  <table class="data-table">
    <thead>
      <tr>
        <th v-for="col in columns" :key="col.key">{{ col.title }}</th>
      </tr>
    </thead>
    <tbody>
      <tr v-for="(row, index) in data" :key="index">
        <!-- 普通列直接渲染 -->
        <td v-for="col in columns" :key="col.key">
          <!-- 如果父组件为该列提供了插槽，用插槽；否则直接显示值 -->
          <slot 
            :name="`cell-${col.key}`" 
            :row="row" 
            :value="row[col.key]"
            :index="index"
          >
            {{ row[col.key] }}
          </slot>
        </td>
      </tr>
    </tbody>
  </table>
</template>

<script setup lang="ts">
defineProps<{
  columns: { key: string; title: string }[]
  data: Record<string, any>[]
}>()
</script>
```

```vue
<!-- 使用：通过作用域插槽自定义列渲染 -->
<Table
  :columns="[
    { key: 'name', title: '姓名' },
    { key: 'status', title: '状态' },
    { key: 'action', title: '操作' }
  ]"
  :data="userList"
>
  <!-- 自定义状态列：加颜色 -->
  <template #cell-status="{ value }">
    <span :class="['status-tag', value]">{{ statusMap[value] }}</span>
  </template>
  
  <!-- 自定义操作列：放按钮 -->
  <template #cell-action="{ row }">
    <button @click="edit(row)">编辑</button>
    <button @click="remove(row)">删除</button>
  </template>
</Table>
```

**这就是 Element Plus 的 `el-table` 核心原理。**

### 3.5 动态插槽名

```vue
<!-- 动态决定用哪个插槽 -->
<slot :name="dynamicSlotName" :data="item"></slot>

<!-- 用法 -->
<template #[`cell-${column.key}`]="{ row }">
  {{ row[column.key] }}
</template>
```

## 四、响应式系统：ref 与 reactive

### 4.1 ref vs reactive 速查表

| 特性 | `ref()` | `reactive()` |
|------|---------|-------------|
| 数据类型 | 任意类型（基本/对象/数组） | 只能是对象或数组 |
| 访问方式 | `.value` | 直接访问 |
| 解构丢失响应式 | 不丢失（仍是 ref） | **丢失**（需 `toRefs`） |
| 适用场景 | 单个值、基本类型、需替换整体的对象 | 结构固定的嵌套对象 |

### 4.2 何时用 ref？

```typescript
// ✅ 基本类型
const count = ref(0)
const message = ref('hello')
const isLoading = ref(false)

// ✅ 需要替换整个对象的场景（API 返回的数据）
const userList = ref<User[]>([])
// 后续整体赋值
userList.value = await fetchUsers()

// ✅ DOM 引用
const inputRef = ref<HTMLInputElement>()
```

### 4.3 何时用 reactive？

```typescript
// ✅ 固定结构的表单对象
const form = reactive({
  username: '',
  password: '',
  rememberMe: false
})

// ✅ 组件内部固定状态的聚合
const state = reactive({
  isExpanded: false,
  selectedKeys: [] as string[],
  filters: { keyword: '', status: '' as '' | 'active' | 'inactive' }
})
```

### 4.4 reactive 解构陷阱与 toRefs

```typescript
const state = reactive({
  count: 0,
  name: 'test'
})

// ❌ 直接解构会丢失响应式！
const { count, name } = state  // 只是普通变量

// ✅ 使用 toRefs 保持响应式
const { count, name } = toRefs(state)  // 现在都是 ref

// 或者解构后单独访问
const countRef = toRef(state, 'count')  // 单个转 ref
```

### 4.5 computed — 派生状态

```typescript
const price = ref(100)
const quantity = ref(3)
const discount = ref(0.1)

// 自动缓存，只有依赖变化才重新计算
const totalPrice = computed(() => {
  return price.value * quantity.value * (1 - discount.value)
})

// 可写的计算属性（较少用）
const doubleCount = computed({
  get: () => count.value * 2,
  set: (val) => { count.value = val / 2 }
})
```

## 五、计算属性与侦听器

### 5.1 watch vs watchEffect 对比

| 特性 | `watch()` | `watchEffect()` |
|------|-----------|----------------|
| 懒执行 | ✅ 默认不立即执行 | ❌ 立即执行一次 |
| 指定源 | ✅ 明确指定要监听什么 | ❌ 自动追踪依赖 |
| 获取旧值 | ✅ 可以拿到 prev 值 | ❌ 没有 |
| 适用场景 | 需要特定条件触发 | 副作用自动跟随数据变化 |

### 5.2 watch 常用模式

```typescript
// 1. 监听单个 ref
watch(count, (newVal, oldVal) => {
  console.log(`count: ${oldVal} → ${newVal}`)
})

// 2. 监听多个源
watch([count, name], ([newCount, newName], [oldCount, oldName]) => {
  // ...
})

// 3. 监听对象深层属性（深度监听）
watch(
  () => form.username,
  (val) => { validateUsername(val) }
)

// 4. 监听整个 reactive 对象
watch(
  form,
  (newForm) => { saveToLocalStorage(newForm) },
  { deep: true }  // 深度监听，性能开销大
)

// 5. 带 immediate 和 flush
watch(
  source,
  callback,
  { 
    immediate: true,     // 立即执行一次
    flush: 'post'        // DOM 更新后执行（访问 updated DOM）
  }
)
```

### 5.3 实战：搜索防抖

```typescript
import { ref, watch } from 'vue'
import { useDebounceFn } from '@vueuse/core'  // 或自己实现

const keyword = ref('')
const searchResults = ref([])

// 防抖搜索
const debouncedSearch = useDebounceFn(async (query: string) => {
  if (!query) {
    searchResults.value = []
    return
  }
  searchResults.value = await api.search(query)
}, 300)

watch(keyword, (val) => {
  debouncedSearch(val)
})
```

## 六、模板语法精讲

### 6.1 插值与表达式

```vue
<template>
  <!-- 基本插值 -->
  <p>{{ message }}</p>
  
  <!-- 表达式 -->
  <p>{{ count + 1 }}</p>
  <p>{{ ok ? 'Yes' : 'No' }}</p>
  <p>{{ message.split('').reverse().join('') }}</p>
  
  <!-- ❌ 不支持：语句和多行表达式 -->
  <!-- {{ const a = 1 }}  错误！ -->
  <!-- {{ if (ok) {} }}   错误！-->
</template>
```

### 6.2 常用指令一览

| 指令 | 作用 | 示例 |
|------|------|------|
| `v-text` | 设置文本内容 | `<div v-text="msg"></div>` |
| `v-html` | 渲染 HTML | `<div v-html="rawHtml"></div>` ⚠️ XSS 风险 |
| `v-show` | 切换 display | `<div v-show="isVisible">` |
| `v-if / v-else-if / v-else` | 条件渲染 | `<div v-if="ok">` |
| `v-for` | 循环渲染 | `<li v-for="item in list">` |
| `v-on / @` | 事件监听 | `<button @click="handle">` |
| `v-bind / :` | 动态绑定 | `<img :src="url">` |
| `v-model` | 双向绑定 | `<input v-model="text">` |
| `v-memo` | 性能优化跳过更新 | `<div v-memo="[items]">` Vue 3.2+ |
| `v-once` | 只渲染一次 | `<span v-once>{{ msg }}</span>` |

### 6.3 v-if vs v-show 选择指南

```vue
<!-- v-if：条件不常变时用，真正地销毁/重建 DOM -->
<div v-if="isLoggedIn">
  欢迎，{{ user.name }}！
</div>
<div v-else>
  请先登录
</div>

<!-- v-show：频繁切换时用，只是切换 CSS display -->
<div v-show="isDetailVisible">
  详情面板（切换很频繁的场景）
</div>

<!--
选择原则：
- 条件很少改变 → v-if（初始渲染开销小）
- 需要频繁切换 → v-show（无需反复创建/销毁）
- SSR 场景下 v-show 始终渲染，v-if 不渲染
-->
```

### 6.4 v-for 的 key 规则

```vue
<!-- ✅ 推荐：用唯一且稳定的 id 作为 key -->
<li v-for="item in list" :key="item.id">{{ item.name }}</li>

<!-- ⚠️ 可以接受：无 id 时用 index（但列表增删会有问题） -->
<li v-for="(item, index) in list" :key="index">{{ item.name }}</li>

<!-- ❌ 禁止：不用 key（Vue 会警告） -->
<li v-for="item in list">{{ item.name }}</li>
```

**为什么 key 很重要？**

```
列表: [A, B, C] → 删除 B → [A, C]

无 key（按位置复用）：A(复用), C(移动到B的位置) → 可能导致状态错乱
有 key（按标识复用）：A(保持), C(保持) → 正确
```

## 七、常用指令实战

### 7.1 动态绑定进阶

```vue
<template>
  <!-- 动态属性名 -->
  <div :[attrName]="value"></div>
  
  <!-- 动态绑定多个属性 -->
  <div v-bind="dynamicAttrs"></div>
  
  <!-- class 的多种用法 -->
  <div 
    class="static-class"
    :class="{ active: isActive, 'text-danger': hasError }"
    :style="{ color: textColor, fontSize: size + 'px' }"
  >
  </div>
  
  <!-- 数组形式的 class -->
  <div :class="[baseClass, { active: isActive }]"></div>
  
  <!-- 样式对象 -->
  <div :style="styleObject"></div>
  <!-- 数组形式的多样式 -->
  <div :style="[baseStyle, overrideStyle]"></div>
</template>

<script setup lang="ts">

const isActive = ref(true)
const hasError = ref(false)
const textColor = ref('#333')
const size = ref(16)

```

### 7.2 事件修饰符速查

```vue
<template>
  <!-- 阻止默认行为（如提交表单、链接跳转） -->
  <form @submit.prevent="handleSubmit">
  
  <!-- 阻止冒泡（点击内部不会触发外部点击） -->
  <div @click.stop="handleDivClick">
    <button @click.stop="handleButtonClick">点我</button>
  </div>
  
  <!-- 只触发一次 -->
  <button @click.once="doOnceAction">仅首次有效</button>
  
  <!-- 事件目标自身才触发（非子元素冒泡上来） -->
  <ul @click.self="handleUlClick">
    <li>项 1</li>
    <li>项 2</li>
  </ul>
  
  <!-- 按键修饰符 -->
  <input @keyup.enter="submit" />
  <input @keyup.esc="cancel" />
  <input @keyup.ctrl.s="save" />  <!-- Ctrl+S 保存 -->
  
  <!-- 鼠标修饰符 -->
  <button @click.left="leftClick">左键</button>
  <button @click.right.prevent="rightClick">右键（阻止菜单）</button>
  
  <!-- 捕获阶段触发（而非冒泡） -->
  <div @click.capture="handleCapture">
  
  <!-- passive：提升滚动性能（不阻止默认行为） -->
  <div @scroll.passive="onScroll">
</template>
```

### 7.3 表单 v-model 修饰符

```vue
<template>
  <!-- .trim：去除首尾空格 -->
  <input v-model.trim="username" />
  
  <!-- .number：转为数字类型 -->
  <input v-model.number="age" />
  
  <!-- .lazy：从 input 事件改为 change 事件（失焦时更新） -->
  <input v-model.lazy="content" />
  
  <!-- 自定义组件的 v-model 参数 -->
  <MyComponent v-model:title="pageTitle" v-model:content="pageContent" />
```

## 八、组件设计模式

### 8.1 受控 vs 非受控组件

```vue
<!-- 非受控：内部维护自己的状态，外部无法直接控制 -->
<template>
  <div class="collapse" @click="toggle">
    <slot name="title"></slot>
    <div v-show="isOpen"><slot /></div>
  </div>
</template>
<script setup>
const isOpen = ref(false)
const toggle = () => isOpen.value = !isOpen.value
</script>


<!-- 受控：完全由外部控制，内部只负责渲染和通知 -->
<template>
  <div class="collapse" @click="$emit('toggle')">
    <slot name="title"></slot>
    <div v-show="modelValue"><slot /></div>
  </div>
</template>
<script setup>
defineProps<{ modelValue: boolean }>()
defineEmits<{ 'update:modelValue': [value: boolean], toggle: [] }>()
</script>
```

### 8.2 Provide / Inject — 跨层级通信

当组件层级较深时，props 逐层传递会很繁琐。provide/inject 可以跨级传递数据：

```typescript
// 祖先组件 - 提供数据
// RootLayout.vue
import { provide, ref } from 'vue'

const theme = ref<'light' | 'dark'>('light')
const toggleTheme = () => {
  theme.value = theme.value === 'light' ? 'dark' : 'light'
}

// provide 响应式数据（用 ref 包装）
provide('theme', theme)
provide('toggleTheme', toggleTheme)

// 后代组件 - 注入数据
// DeepChild.vue
import { inject } from 'vue'

const theme = inject<Ref<'light' | 'dark'>>('theme')
const toggleTheme = inject<() => void>('toggleTheme')

// 使用
<button @click="toggleTheme">
  当前主题: {{ theme?.value }}
</button>
```

**适用场景：**
- 全局主题切换
- 表单 Form / FormItem 联动
- 国际化 i18n 语言包
- 权限校验上下文

### 8.3 通用组件 Checklist

设计一个通用组件前，问自己这些问题：

| ✅ 检查项 | 说明 |
|-----------|------|
| Props 类型安全？ | 用 TypeScript 接口定义 |
| Props 有合理默认值？ | `withDefaults` 处理可选 prop |
| 支持 v-model？ | 需要双向绑定时实现 |
| 提供了足够的插槽？ | 让调用方可以自定义内容 |
| emit 事件命名清晰？ | 用动词开头：`change`, `select`, `close` |
| 样式可定制？ | 通过 CSS 变量或 props 暴露关键样式 |
| 无障碍（a11y）？ | 语义化标签、键盘导航、ARIA 属性 |
| 加载/空状态？ | 数据异步时的 loading 和 empty 状态 |

### 9.2 实战二：Modal 弹窗组件

支持遮罩层关闭、ESC 关闭、锁定滚动、动画过渡的完整弹窗：

```vue

          @click.stop
        >
          <!-- 头部 -->
          <div v-if="showHeader" class="modal-header">
            <slot name="header">
              <h3 class="modal-title">{{ title }}</h3>
            </slot>
            <button class="modal-close" @click="close">✕</button>
          </div>
          
          <!-- 内容区 -->
          <div class="modal-body">
            <slot></slot>
          </div>
          
          <!-- 底部按钮 -->
          <div v-if="showFooter" class="modal-footer">
            <slot name="footer">
              <button class="btn btn-default" @click="close">取消</button>
              <button class="btn btn-primary" @click="handleConfirm">确定</button>
            </slot>
          </div>
        </div>
      </div>
    </Transition>
  </Teleport>

  title?: string
  width?: string
  maxWidth?: string
  showHeader?: boolean
  showFooter?: boolean
  maskClosable?: boolean
  escClosable?: boolean

  'update:modelValue': [value: boolean]

onUnmounted(() => window.removeEventListener('keydown', onEsc))
</script>
```

### 9.5 实战五：ConfirmDialog 确认对话框

基于 Modal 封装，返回 Promise，支持 async/await 调用风格：

```vue
<!-- ConfirmDialog.vue -->
<template>
  <MyModal v-model:visible="visible" :title="title" width="400px">
    <p class="confirm-msg">{{ message }}</p>
    <template #footer>
      <button class="btn btn-default" @click="handleCancel">取消</button>
      <button class="btn btn-danger" @click="handleConfirm">{{ confirmText }}</button>
    </template>
  </MyModal>
</template>

<script setup lang="ts">
import { ref } from 'vue'

interface Props {
  title?: string
  confirmText?: string
}

withDefaults(defineProps<Props>(), {
  title: '确认操作',
  confirmText: '确定'
})

const visible = ref(false)
const message = ref('')
let resolvePromise: ((value: boolean) => void) | null = null

const confirm = (msg: string): Promise<boolean> => {
  message.value = msg
  visible.value = true
  return new Promise((resolve) => {
    resolvePromise = resolve
  })
}

const handleConfirm = () => {
  visible.value = false
  resolvePromise?.(true)
}

const handleCancel = () => {
  visible.value = false
  resolvePromise?.(false)
}

// 暴露方法给父组件通过 ref 调用
defineExpose({ confirm })
</script>

<style scoped>
.confirm-msg { color: #606266; font-size: 14px; line-height: 1.6; margin: 10px 0; }
.btn-danger { background: #f56c6c; color: white; border-color: #f56c6c; }
</style>
```

**使用方式（函数式调用）：**

```vue

  <ConfirmDialog ref="confirmRef" title="危险操作" confirmText="确认删除" />
  <button @click="handleDelete">删除文章</button>
</template>

import { ref } from 'vue'
import ConfirmDialog from './ConfirmDialog.vue'

const confirmRef = ref<InstanceType<typeof ConfirmDialog>>()

  const confirmed = await confirmRef.value!.confirm('删除后不可恢复，是否继续？')
  if (confirmed) {
    await api.deleteArticle()
    alert('删除成功')
  }
}
</script>
```

## 总结：基础组件开发要点回顾

| 知识点 | 一句话总结 |
|--------|-----------|
| SFC 结构 | template + script setup + style scoped |
| Props | 用 TypeScript 接口定义，`withDefaults` 设默认值 |
| Emits | TypeScript 泛型定义，动词命名事件 |
| 插槽 | 默认 → 具名 → 作用域（递进学习） |
| 响应式 | 基本类型用 `ref`，固定对象用 `reactive` |
| 生命周期 | `onMounted` 初始化，`onUnmounted` 清理（成对出现） |
| v-model | `modelValue` + `update:modelValue` 语法糖 |
| 设计原则 | Props 向下，Events 向上，插槽扩展内容 |
