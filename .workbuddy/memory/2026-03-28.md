## 目录锚点 ID 生成规则（重要！）

`parseMarkdown` 函数会根据标题的完整文本生成锚点 ID：

```javascript
// 标题：## 1. Webpack 基础概念
// 生成 ID：#1-webpack-基础概念
// 编号会被包含在 ID 中！

// 标题：## Vite 简介
// 生成 ID：#vite-简介
// 无编号的标题直接生成 ID
```

**关键点**：如果标题包含编号，目录链接的锚点 ID 必须包含编号，否则跳转不工作！

## 完成的工作

### 1. 添加目录数据结构 (TocItem 接口)

```typescript
interface TocItem {
  id: string      // 标题的锚点 ID
  text: string    // 标题文本
  level: number   // 标题级别 (h2/h3)
}
```

### 2. 更新 parseMarkdown 函数

修改了 Markdown 解析函数,使其能够:
- 为所有标题 (h1-h6) 自动生成锚点 ID
- 收集 h2 和 h3 级别标题到目录数组
- 返回包含 title, content, toc 的对象

### 3. 添加目录模板结构

在 `Article.vue` 模板的 `<header>` 和 `<div class="article-content">` 之间添加了:

```vue
<!-- 文章目录 -->
<div class="article-toc" v-if="tocItems.length > 0">
  <h3 class="toc-title">📖 文章目录</h3>
  <ul class="toc-list">
    <li v-for="(item, index) in tocItems" :key="index" class="toc-item"
        :class="{ 'toc-item-h2': item.level === 2, 'toc-item-h3': item.level === 3 }">
      <a :href="`#${item.id}`" class="toc-link" @click.prevent="scrollToAnchor(item.id)"
         :class="{ 'active': activeTocId === item.id }">
        {{ item.text }}
      </a>
    </li>
  </ul>
</div>
```

### 4. 实现目录高亮功能

添加了三个新函数:
- `updateActiveToc()` - 根据当前滚动位置更新激活的目录项
- `initTocHighlight()` - 初始化目录高亮监听
- 在 `handleScroll()` 中调用 `updateActiveToc()`

### 5. 优化目录样式

更新了目录的 CSS 样式:
- `.article-toc` - 添加背景色和圆角,更美观
- `.toc-item-h2` / `.toc-item-h3` - 不同级别标题的缩进
- `.toc-link` - 悬停效果和激活状态样式
- `.toc-link.active` - 当前章节高亮显示

## 技术细节

### 目录高亮算法
1. 监听页面滚动事件
2. 获取所有目录项对应的标题元素
3. 遍历标题元素,找到当前视口中最近的标题
4. 更新 `activeTocId` 状态
5. Vue 自动更新激活状态的样式

### 性能优化
- 使用 `{ passive: true }` 监听滚动,提高性能
- 在 `onUnmounted` 时清理事件监听器,避免内存泄漏

## 注意事项

1. **文章必须有 h2 或 h3 标题**才会显示目录
2. 目录在文章加载 100ms 后才初始化高亮(等待 DOM 渲染)
3. 跳转时有 80px 的顶部偏移,避免被导航栏遮挡
